# Everly - Wedding Planning Android Application

## Introduction

Everly is a comprehensive Android application designed to simplify and streamline the wedding planning process. Built as part of the Advanced Mobile Development (COM640) module, this application addresses the complex organizational challenges faced by couples planning their special day. The name "Everly" represents the eternal bond and everlasting love that weddings celebrate.

## Project Overview

Planning a wedding involves coordinating numerous details, managing multiple vendors, tracking budgets, and ensuring every guest is accommodated. Everly consolidates all these essential tasks into a single, intuitive mobile application that leverages Android's native capabilities to provide a seamless user experience.

## Core Features

### 1. Guest Management System
- Comprehensive guest list with contact information
- RSVP tracking with real-time status updates
- Dietary restrictions and special requirements logging
- Plus-one management and family grouping
- Digital invitation system with response notifications

### 2. Event Planning Hub
- Master timeline with countdown to wedding day
- Milestone tracking and deadline reminders
- Task assignment to wedding party members
- Venue comparison tools with photo galleries
- Vendor management with contact details and contracts

### 3. Budget Planning & Tracking
- Comprehensive budget categories (venue, catering, photography, etc.)
- Real-time expense tracking with receipt photo capture
- Payment scheduling and vendor payment tracking
- Budget vs. actual spending analysis
- Cost comparison tools for different vendors

## Advanced Features

### Android Platform Integration
- **Camera Integration**: Capture venue photos, outfit selections, and receipts directly within the app
- **Calendar Synchronization**: Seamless integration with Android calendar for appointments and deadlines
- **Push Notifications**: Intelligent reminders for important deadlines and RSVP responses
- **Location Services**: GPS integration for venue directions and location-based vendor recommendations

### Enhanced Planning Tools
- **Seating Chart Designer**: Visual drag-and-drop interface for table arrangements
- **Menu Planning System**: Meal selection with dietary restriction tracking
- **Wedding Party Coordination**: Role assignments and communication hub
- **Photo Gallery**: Inspiration boards and planning photo storage

## Technical Architecture

Everly follows modern Android development best practices:
- **MVVM Architecture Pattern**: Ensuring clean separation of concerns
- **Room Database**: Local data persistence for offline functionality
- **Material Design 3**: Consistent and intuitive user interface
- **Kotlin**: Primary development language for robust and concise code
- **Android Jetpack Components**: Navigation, ViewModel, and LiveData integration

## Target Users

- Engaged couples planning their wedding
- Wedding planners and coordinators
- Family members involved in wedding organization
- Anyone seeking organized event planning capabilities

## Development Goals

This application demonstrates proficiency in:

Everly aims to transform the wedding planning experience from overwhelming chaos into an organized, enjoyable journey. By combining powerful functionality with elegant design, Everly ensures that couples can focus on what truly matters - celebrating their love and creating lasting memories.

Everly represents a complete mobile solution that showcases advanced Android development skills while solving real-world problems. The application balances feature richness with usability, ensuring that couples can navigate their wedding planning journey with confidence and joy.
